كيف بنيت سكريبت بسيط يؤتمت مهام متكررة ويوفر وقتاً ثميناً — وكيف تبدأ مثلي.

كل مبرمج مبتدئ يسأل: "ما أول مشروع أنشئه؟" — جوابي دائماً: اصنع شيئاً يحل مشكلة تواجهها أنت. هذا بالضبط ما فعلته.

المشكلة اللي واجهتها

كنت كل أسبوع أنظّم ملفات مجلد التنزيلات يدوياً — صور هنا، PDFs هناك، فيديوهات في مكان ثالث. عملية مملة تأخذ 10-15 دقيقة. قررت أكتب سكريبت بايثون يسوي هذا تلقائياً.

الفكرة الأساسية

السكريبت يراقب مجلداً معيناً، وكل ما يجد ملف جديد يصنّفه حسب امتداده ويحركه للمجلد المناسب تلقائياً.

💡 المكتبات المستخدمة

os, shutil, watchdog — كلها مجانية ومثبّتة مع Python أو بأمر pip واحد.

الكود الأساسي

import os import shutil from pathlib import Path # تعريف المجلدات DOWNLOADS = Path.home() / "Downloads" FOLDERS = { "صور": [".jpg", ".jpeg", ".png", ".gif", ".webp"], "فيديو": [".mp4", ".mkv", ".avi", ".mov"], "مستندات":[".pdf", ".docx", ".xlsx", ".pptx"], "برامج": [".exe", ".apk", ".dmg", ".zip"], "أكواد": [".py", ".js", ".html", ".css"], } def get_folder(extension): for folder, exts in FOLDERS.items(): if extension.lower() in exts: return folder return "أخرى" def organize(): for file in DOWNLOADS.iterdir(): if file.is_file(): dest = DOWNLOADS / get_folder(file.suffix) dest.mkdir(exist_ok=True) shutil.move(str(file), dest / file.name) print(f"نقل: {file.name} → {dest.name}") if __name__ == "__main__": organize() print("✅ تم تنظيم المجلد!")

كيف أشغّله؟

  1. تأكد إن Python مثبّت عندك
  2. احفظ الكود في ملف اسمه organizer.py
  3. افتح Terminal أو CMD في نفس المجلد
  4. شغّله بالأمر: python organizer.py

التطوير: المراقبة التلقائية

الإصدار الأول كان يشتغل مرة واحدة فقط. طورت المشروع ليراقب المجلد بشكل مستمر باستخدام مكتبة watchdog:

pip install watchdog
from watchdog.observers import Observer from watchdog.events import FileSystemEventHandler import time class Handler(FileSystemEventHandler): def on_created(self, event): if not event.is_directory: file = Path(event.src_path) dest = DOWNLOADS / get_folder(file.suffix) dest.mkdir(exist_ok=True) time.sleep(1) # انتظر اكتمال التنزيل shutil.move(str(file), dest / file.name) observer = Observer() observer.schedule(Handler(), str(DOWNLOADS), recursive=False) observer.start() print("🔍 جاري المراقبة... Ctrl+C للإيقاف") try: while True: time.sleep(1) except KeyboardInterrupt: observer.stop()
